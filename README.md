# Marketplace Calculator

A web application designed to help online sellers calculate marketplace fees, product costs, selling prices, and profit margins.

The project is being developed from scratch as a practical study of web development using Python, Flask, HTML5, CSS3, JavaScript, and SQL.

## 🚀 Project Goals

The main goal is to create a simple platform for managing products and analyzing their profitability across different online marketplaces.

The application will eventually allow users to:

* Register products
* Store purchase and selling prices
* Select the marketplace where the product will be sold
* Calculate marketplace fees
* Calculate estimated profit
* Calculate profit margins
* Save products to a database
* Edit and delete registered products
* View previously registered products
* Analyze sales and profitability
